# 食材アイコン対応表

ユーザーが提供してくれた、ポケモンスリープの全19食材アイコンと名前の
対応表。画像本体は同じディレクトリの `ingredient-icons-reference.jpg`。

ゲーム画面のスクリーンショットに写っている食材アイコンを識別する際は、
この画像を参照すること。ロック中(未解放)のスロットは、実際の食材が
まだゲーム側で明かされておらず、代わりに仮のアイコン(解放済みの
スロットと同じ絵など)が表示されていることがあるため、ロック中の
アイコンから食材名を判別しようとしないこと。判別できるのは、その
個体で実際に解放済み(ロックなし)のスロットのアイコンのみ。
