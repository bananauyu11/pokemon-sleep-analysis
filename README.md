# ポケスリ分析

「ポケモンスリープ」で捕獲したポケモンの記録(サブスキル・食材配列・性格・メダル状況など)を
蓄積し、サブスキルの出現傾向をメダル状況やとくい分野(きのみ/食材/スキル)別に分析するための
個人用ツールです。Next.js製で、Vercel上で動かすことを想定しています。

## 主な機能

- **手動入力**: レベル・性格・メダル状況・サブスキル(Lv10/25/50/70/80)・食材配列などをフォームから登録
- **画像取込(OCR)**: ゲーム画面のスクリーンショットから時刻・ポケモン名・レベル・メインスキルをブラウザ内OCR(Tesseract.js)でベストエフォート抽出し、確認・修正してから登録
- **CSV取込/出力**: 記録一覧をCSVで入出力(バックアップや端末間の共有に利用可能)
- **種族マスタ**: ポケモンスリープ攻略・検証Wikiの情報をもとに、全247種の「きのみ/食材/スキル」タイプ・きのみ名・メインスキル・食材を内蔵データとして登録。ポケモンの名前を入力するとこれらが自動入力される(アプリ内に編集画面はなく、新ポケモン追加や修正はソースコード側で対応する運用)
- **分析ダッシュボード**: サブスキルごとの出現回数・保有割合を、メダル状況/とくい分野でグルーピングした棒グラフで表示。食材配列パターン(AAA/AAB/ABC)の分布も表示
- **PWA対応**: スマートフォンのホーム画面に追加すると「ポケスリ分析」として起動できます

## データの保存について

データはすべてブラウザのIndexedDBにこの端末だけで保存されます(サーバー送信なし)。
他の端末と共有したり、バックアップを取りたい場合は「記録一覧」画面の
CSVエクスポート/インポートをご利用ください。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## ビルド

```bash
npm run build
npm run start
```

## Vercelへのデプロイ

このリポジトリをVercelにインポートするだけで、追加設定なしにデプロイできます
(データベースや環境変数は不要です)。
